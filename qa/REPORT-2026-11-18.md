## Found and fixed

| # | Severity | Page | Issue | Fix |
|---|---|---|---|---|
| 1 | 🔴 | Cart drawer | **Esc did not close the drawer** when it was opened with the mouse: the listener sat on the drawer, but focus stays on the header icon | `assets/cart-drawer.js` listens on `document` while the drawer is open |
| 2 | 🟠 | FAQ | The page had **no H1**: the page title is hidden and the FAQ heading was an H2 | `faq-accordion` gets the setting "Use the heading as the page title (H1)". It is on in `page.faq.json` |
| 3 | 🟠 | Article (tablet 750–991px) | Horizontal scroll of 17px: the decorative disc behind the hero photo stuck out of the column | The disc shows only from 992px up |
| 4 | 🔵 | Login | Console error "Provider's accounts list is empty". This is Shopify's FedCM sign-in probe, not theme code | Ignored in `tests/helpers.js` |
| 5 | 🔵 | Visual tests | Flaky: full-page capture painted rows of lazy images the viewport never reached | The test loads every image eagerly, waits for the network, and decodes each image (max 3s) before capture. Baselines retaken |

## Re-run 2026-11-19 — all browsers

The projects now include Firefox, WebKit desktop and iPhone 14 (WebKit). These use Playwright's bundled engines; install them on each machine with `npx playwright install firefox webkit`. This run covers the 2026-11-18 evening work (card hover box, type scale, catalogue with a photo per colour).

| Project | Result |
|---|---|
| Chrome desktop / tablet / mobile, Edge, Firefox, WebKit, iPhone | **274 passed, 0 failed**, 25 skips by design. The one first-run failure was fixed (see below) and its projects re-run green |

Fixed:
- 🟠 **iPhone (WebKit), About page**: horizontal scroll of 16px. The leaf-branch decor of the `mc-story` art hangs past the photo, and WebKit counts it in the page width (Chrome does not). Fix: `.mc-story { overflow-x: clip }`.
- 🟠 **PDP, desktop**: the "ADD TO CART" label was cut off once content text went to 1.6rem. Both buttons now keep their label width. When the row is too tight, the wish-list button wraps below and fills the row. Measured at 1440 / 1200 / 1024 / 768 / 390: no clipped label.
- 🔵 Tests:
  - The empty-search query is now a nonsense string. Shopify search is typo-tolerant and matched "zzqqxxnothing" to a product.
  - Firefox's `_shopify_test` cookie warning is ignored, because it comes from Shopify, not the theme.
  - Running 7 projects at once can hit the storefront rate limit; a re-run passes.

Visual baselines were retaken for the new card hover box and type scale, after a visual check of home, collection and product.
